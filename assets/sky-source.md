# Sky background

`sky.png` is a 4096 x 2048 display conversion of the celestial-coordinate
**Deep Star Maps 2020** all-sky image, including real stars and the Milky Way.

Source: https://svs.gsfc.nasa.gov/4851/

Original: https://svs.gsfc.nasa.gov/vis/a000000/a004800/a004851/starmap_2020_4k.exr

Credit: NASA/Goddard Space Flight Center Scientific Visualization Studio.
Visualization: Ernie Wright. Gaia DR2: ESA/Gaia/DPAC.

The original floating-point image was converted once to an RGB PNG for the app's
existing image loader. The app loads the bundled image offline. It is a static
astronomical background, without date simulation, labels, or moving Solar System objects.

Source EXR SHA-256: `69b841cd048c2ef35543eb1c5819b322530e78aa4b0cab97ec1de3ef56a4ddcd`.
